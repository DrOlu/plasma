# Plasma architecture — moved

This page described an earlier architecture (WHIDS as a response engine with
kill/dump actions). WHIDS remains detect-only; response and prevention are
separate, opt-in planes in Plasma itself. This page is kept only as a
redirect.

The current architecture is documented at:

- <https://drolu.github.io/plasma/concepts/>
- <https://drolu.github.io/plasma/sensors/>
